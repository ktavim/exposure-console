Exposure console prototypes

Three throwaway directions, each with the grouping workspace and the plan review, built from the same data (data.js). Switch between the two screens with the prototype toggle in each page's top bar. Compare them against the criteria in docs/exposure-console-ui.md, not only on looks.

  1. A · Dense tables: light and compact. Grouping is one table with a VIP picker per row. The plan review has tabs, a unified diff, and a sticky confirm bar with the warnings and an acknowledgement checkbox, then a danger dialog.
  2. B · Run page: dark, roomy, with a step timeline. Grouping uses a card per VIP, with drag and drop or a Move menu. The plan review has summary cards, a split diff, and a deploy bar where you type the app's name to confirm.
  3. C · Master and detail: light or dark. The left pane lists VIPs and sections; the right pane shows the selected one. Grouping is columns with drag and drop and keyboard moves (focus a card, press 1–9, N or 0). The plan review is laid out like a pull request's changed files, with a drawer where you acknowledge each warning before deploying.
